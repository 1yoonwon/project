# 🌙 Moodlog — AI 감정 일기장

오늘의 감정을 이모지로 기록하고, AI의 따뜻한 공감 한 마디를 받아보세요.

## 주요 기능

- **감정 기록** — 이모지 선택 + 짧은 일기 작성
- **AI 공감 응답** — Google Gemini가 한 문장으로 위로
- **일기 목록** — 과거 기록 카드 형태로 조회 / 삭제
- **감정 통계** — 이번 달 달력 + 이모지별 빈도 그래프

## 기술 스택

- React + Vite
- Google Gemini API
- LocalStorage (서버 없음)

## 사용 방법

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키 발급
2. 앱 상단 입력창에 API 키 입력 후 저장
3. 이모지 선택 → 일기 작성 → 저장

## 로컬 실행

```bash
npm install
npm run dev
```
